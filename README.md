# ✝️ Biblical End Times

A modern, responsive website that explores the biblical teachings about the End Times through Scripture, timelines, and key prophetic events. This project is designed to present biblical prophecy in a clear, accessible, and engaging format for anyone interested in studying biblical endtimes.

## 🌐 Live Website

🔗 **Visit the site:**  
(https://shadow-lofi.github.io/Oil-In-My-Lamp/)

---

## 📖 About the Project

The **Biblical End Times** website provides an overview of major end-time events described in the Bible. Rather than promoting a specific interpretation, it encourages readers to explore Scripture and deepen their understanding of biblical prophecy.

Topics include:

- 📜 Signs of the End Times
- 🌍 The Great Tribulation
- 👑 The Antichrist
- ✝️ The Second Coming of Jesus Christ
- ⚔️ Armageddon
- 🎭 Deception
- ⚖️ The Final Judgment
